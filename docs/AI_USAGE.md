I used AI tools as supporting resources throughout the development of the Returns Management System.

AI assistance was mainly used for:

- Understanding and breaking down project requirements.
- Exploring application architecture and implementation approaches.
- Planning development tasks and identifying suitable technologies.
- Clarifying technical concepts and resolving implementation doubts.
- Debugging issues and suggesting possible solutions.
- Improving code structure and documentation.
- Learning dashboard development concepts, data visualization techniques and interactive UI design.

## 3. Development Approach

I followed an iterative development approach, using AI as a supporting tool throughout the project.

I used AI to support planning, explore implementation strategies, clarify technical doubts and troubleshoot issues during development.

The development involved translating requirements into application components, implementing business logic, integrating different modules and refining the application through repeated testing and debugging.

AI suggestions were reviewed and applied where appropriate rather than being treated as final solutions.
